# Creative Brainstorming

Techniques for widening the option space. Reach for them when the first obvious ideas are not enough.

- Generate in quantity before judging: separate the divergent pass from the selection pass.
- SCAMPER: substitute, combine, adapt, modify, put to other use, eliminate, reverse — apply each
  verb to the current concept to force mutations.
- Change a constraint deliberately: budget, medium, audience, era, scale, or seriousness;
  "what if this had to work for children / in 1970 / with no budget" reshapes stale ideas.
- Steal structures across domains: map a proven pattern from music, cuisine, architecture, or
  games onto the problem at hand.
- Invert: design the worst possible version, then flip it; or solve the opposite problem.
- Combine unrelated inputs: pair the problem with a random object, headline, or image and
  bridge the gap.
- For each shortlist idea, name its seed of value and its first failure mode — this makes
  selection a discussion instead of a vote.
- Return to the brief between rounds: fresh constraints often beat more ideas.

These are prompts for invention, not rules. The user's taste decides what survives.
